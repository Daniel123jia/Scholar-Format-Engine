# Style Pack design

A Style Pack is the only place that should encode reusable formatting decisions.

Do not hard-code project-specific fonts, spacing, margins, or colors in domain adapters.

Use Style Packs for:

- page geometry;
- title and heading hierarchy;
- body typography;
- table padding and borders;
- callout colors;
- metadata presentation;
- TOC / header / footer;
- evidence display policy;
- human-facing vs technical metadata policy.

Exact school, journal, funder, or organization requirements should be represented as a dedicated Style Pack.
