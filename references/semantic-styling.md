# Semantic styling system

Scholar-Format-Engine uses visual hierarchy to reduce reading effort.

## Three rules

1. Bold communicates importance.
2. Color communicates semantic type.
3. Spacing communicates hierarchy.

## Default semantic roles

| Role | Meaning | Default treatment |
|---|---|---|
| key_takeaway | highest-level takeaway | primary indigo accent, bold title |
| judgment | research judgment / Gap interpretation | soft purple, restrained body |
| claim | claim + bounded evidence | soft evidence blue |
| assumption | assumption / mechanism condition | soft purple |
| risk | core weakness / caution | soft amber, not bright red |
| evidence | verbatim source / source locator | soft blue-gray, smaller text |
| research_direction | bounded follow-up direction | soft primary tint |
| reading_path | source navigation | quiet teal/neutral accent |
| secondary | metadata / boundary note | gray, smaller text |

## Bold discipline

Bold only the label or decisive phrase, e.g.:

- **核心缺陷：** …
- **最强证据：** …
- **为什么重要：** …
- **如何验证：** …

Do not bold entire explanatory paragraphs.

## Color discipline

Use no more than one primary family plus evidence blue and caution amber in the default academic pack. The document should still be readable in grayscale.
